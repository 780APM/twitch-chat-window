# Twitch Chat Window brand assets

The mark pairs a violet tile with a dark chat bubble and two lines of text. Use it as the app icon or anywhere the full product name would be too small to read.

| Asset | Use |
| --- | --- |
| [Mark](mark.svg) · [PNG](mark.png) | Square logo with a transparent background |
| [Wordmark](wordmark.svg) · [PNG](wordmark.png) | Full product name and tagline on a dark panel |
| [Windows icon](TwitchChatWindow.ico) | Multi-size icon embedded in the EXE |
