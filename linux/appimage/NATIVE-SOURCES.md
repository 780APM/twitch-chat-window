The AppImage bundles GTK 3 and its supporting native libraries from the Ubuntu
22.04 build environment. Package versions and their source-package versions are
recorded in build-packages.tsv; package copyright notices are included here.

Corresponding distribution source packages are available at:
https://launchpad.net/ubuntu/+source/SOURCE-PACKAGE/SOURCE-VERSION

The .NET and GtkSharp notices and source link are under
usr/lib/twitch-chat-window/licenses inside the AppImage. The AppImage runtime is
from https://github.com/AppImage/type2-runtime and its source is available there.
